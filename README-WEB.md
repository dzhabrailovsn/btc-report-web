# BTC «Уровень + поток» — портативная веб-версия

Полный конвейер ежедневного отчёта по BTC: уровни + производные + ликвидации + ETF + сентимент + опции + ИИ-слой.
Пакет самодостаточен: все пути относительные (каталог скрипта), работает на Windows/Linux/macOS, внешние зависимости — только `matplotlib` и `numpy`.

## Состав

| Файл | Назначение |
|---|---|
| `update_report.py` | Оркестратор: гоняет цепочку шагов, пишет `report_run.log`, итог OK/PARTIAL/FAIL |
| `btc_fetch_extra.py` | Внешние данные: F&G, доминация, стейблкоины, ETF (Farside, со сверкой), DXY/NASDAQ |
| `btc_full.py` | Движок: 1Dutc-свечи, причинные уровни, каскады, чек-лист, стакан, опции + график |
| `btc_liqmap.py` | Модель ликвидаций (ΔOI×taker×плечи) + график |
| `btc_backtest.py` | Самопроверка: строгий протокол с издержками + чувствительность |
| `btc_report_html.py` | Сборка самодостаточного `btc_report.html` (графики base64) |
| `events_update.py` | Безопасное слияние календаря событий (дедуп, backup) |
| `events.json` | Календарь: CPI/FOMC/PCE/праздники/конференции |
| `requirements.txt` | Зависимости |

Переменная окружения `BTC_REPORT_DIR` (необязательна) переопределяет каталог вывода.

## Запуск вручную

```sh
pip install -r requirements.txt
python update_report.py        # весь конвейер, 2–5 минут
# → btc_report.html в этом же каталоге
```

Частичный прогон: `python btc_full.py` → `python btc_report_html.py` (без внешних метрик).

## Настройка в Z.ai веб-версии

1. Создайте проект/чат в веб-версии и загрузите все файлы пакета в рабочее пространство проекта.
2. Создайте автоматизацию (scheduled task) с расписанием `20 0,5 * * *` (03:20 и 08:20 МСК = UTC+3) и промптом из `AUTOMATION_PROMPT.md` (скопируйте целиком).
3. Требования к среде веб-версии: запуск Python-скриптов, веб-поиск, сохранение файлов проекта между запусками (для `events.json` и `ai_take.json`).
4. Убедитесь, что на первом ручном прогоне `python update_report.py` завершился с итогом OK.

Проверка после настройки: на следующее утро агент должен прислать сводку со ссылкой на `btc_report.html`.

## ИИ-слой

Детерминированный движок считает факты; агент (автоматизация) добавляет:
- `ai_take.json` — вердикт, уверенность, причины, аллокация капитала (размер = 100×риск% / дистанция стопа%), гео-новости ≤3 дней, инвалидация;
- пополнение `events.json` через `events_update.py` (веб-поиск дат CPI/FOMC/конференций);
- пересборку HTML после вердикта.

Без ИИ-слоя отчёт тоже собирается — просто без секции «ИИ-рассуждение» и свежего календаря.

## Ограничения

- Источники: OKX/Binance/Bybit/Deribit/Farside/CoinGecko/alternative.me/Yahoo — публичные, без ключей; гео-блоки (HTTP 451) возможны, движок уходит на фолбэки, сбой источника не роняет отчёт (итог PARTIAL).
- Автоматизация работает, пока запущен исполнитель (облако веб-версии — всегда; локальный ПК — только включённым).
- Не является инвестиционной рекомендацией.
