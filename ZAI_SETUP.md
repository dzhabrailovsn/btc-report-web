# Перенос ежедневного отчёта BTC на chat.z.ai (облако, scheduled)

Готовый пакет: `btc_report_web.zip` — самодостаточный конвейер (проверен полным прогоном: итог OK, все 5 шагов зелёные). Никаких путей от вашего ПК: все файлы создаются рядом со скриптами.

## Шаг 1 — загрузка пакета (один раз)

1. Откройте https://chat.z.ai/ и создайте **новый чат** (например, с названием «BTC отчёт»).
2. Прикрепите к сообщению файл `btc_report_web.zip` и напишите: «Распакуй архив в рабочую папку и запусти `python update_report.py` из папки btc_report_web; потом пришли btc_report.html». Если в песочнице нет matplotlib — попроси: «установи зависимости: pip install matplotlib numpy».
3. Убедитесь, что прогон закончился `[=== итог: OK ===]` и агент прислал `btc_report.html`.

## Шаг 2 — scheduled-задача

1. В этом же чате создайте автоматизацию/scheduled task (функция «Задачи/Расписание» в chat.z.ai).
2. Расписание: **`20 0,5 * * *`** (00:20 и 05:20 UTC = 03:20 и 08:20 МСК — закрытие D1 UTC в полночь + утренний полный прогон).
3. Промпт задачи: скопируйте **целиком** содержимое `AUTOMATION_PROMPT.md` из пакета.
4. Сохраните. На следующее утро придёт сводка с файлом отчёта.

## Шаг 3 — проверка (первое утро)

Убедитесь, что в сводке есть: статус (OK/PARTIAL), цена BTC, вердикт движка и ИИ-вердикт с рекомендацией по капиталу. Если вместо этого ошибка — пришлите текст ошибки в этот чат.

## Если песочница chat.z.ai не запускает Python

Запасной режим — «одно-промптовый»: создайте scheduled-задачу с промптом из `PROMPT_BTC_REPORT.md` (методология целиком, но без наших скриптов — агент делает разбор сам через веб-поиск). Это менее детерминированно, но работает в любом чате с веб-доступом.

## Замечания

- Файлы чата (`events.json`, `ai_take.json`, кэши) живут в рабочем пространстве чата — автоматизация должна запускаться в том же чате, где распакован пакет.
- Десктоп-автоматизация в ZCode продолжает работать параллельно; отключить её можно в настройках автоматизаций ZCode (мне скажите — сделаю).
- `BTC_REPORT_DIR` — необязательная переменная для переопределения папки вывода.
- Источники публичные, без ключей; при гео-блоке источника движок уходит на фолбэк (итог PARTIAL — это нормально).
